# Loan Approval Prediction using Machine Learning

## Project Overview

This project predicts whether a loan application will be approved or rejected using machine learning.

Objectives

- Analyze loan applicant data.
- Identify factors affecting loan approval.
- Predict loan status using Logistic Regression.

Dataset

The dataset contains applicant details such as:

- Gender, Marital Status, Education
- Applicant and Coapplicant Income
- Loan Amount and Loan Term
- Credit History and Property Area
- Loan Status

Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow

1. Load and understand the dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Handle missing values and encode categorical data.
4. Split data into training and testing sets.
5. Scale features and train a Logistic Regression model.
6. Predict loan approval status.

Key Findings

- Applicants with good credit history show more loan approvals.
- Semiurban applicants have more approvals in the dataset.
- Graduates have more approvals than non-graduates.

Model

Logistic Regression is used to predict loan approval status.

How to Run

1. Clone or download this repository.
2. Install the required libraries:
   pip install pandas numpy matplotlib seaborn scikit-learn
3. Open the Jupyter Notebook.
4. Run all cells.

Conclusion

This project uses applicant information and machine learning to predict loan approval status.
